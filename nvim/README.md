# Neovim Config

## Prerequisites

### Formatters (conform.nvim)

```sh
npm install -g @fsouza/prettierd eslint_d
brew install stylua
```

### LSP Servers

```sh
npm install -g @vtsls/language-server @tailwindcss/language-server
brew install lua-language-server
```

### fzf-lua

```sh
brew install fzf ripgrep fd bat
```
